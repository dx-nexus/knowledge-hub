結論： 「AIネイティブなDX研修動画の自動生成・定期配信サービス」は、 現時点で本格参入プレイヤーがほぼ存在しない真のブルーオーシャン。 はんちょーの技術スタック（Claude Code × GitHub Actions × NotebookLM × 七那華）が そのままサービスの競争優位になる。

競合分析と差別化
競合カテゴリ 弱点 はんちょーの優位性
従来のDX研修会社 制作コスト高・更新遅延・内容が古い Claude Code で最新AI情報を週次動画化。コスト10分の1以下。
AI動画生成SaaS（Synthesia等） 「AI知識を教える」コンテンツがない・テンプレ感が強い はんちょーのDX・4Dフレームワーク知識 × 七那華のキャラクター性で差別化。
フリーランスDX講師 スケールしない・時間を売っている 七那華が24時間稼働。1契約が増えてもコストはほぼ変わらない。
他AIアバター系VTuber エンタメ特化・法人向けコンテンツがない 「AI研修のプロ」というブランドで法人市場を独占ポジション狙い。
サービス提供フロー（MVP設計）
1
ヒアリング → config.json 生成（Claude ブラウザ）
法人クライアントの「DX研修で伝えたいこと・社員のレベル感・研修テーマ」を対話でヒアリング。 Claude が構造化した動画台本仕様 JSON を生成。
2
台本自動生成 + 七那華ナレーション（Claude Code + NotebookLM）
NotebookLM に蓄積した最新AI知識を参照し、Claude Code が動画台本 HTML を自動生成。 七那華のアバター（IRIAMまたはHeygen等）にテキストを読み上げさせる。
3
動画編集 → GitHub Pages or LMS にデプロイ（Claude Code）
生成された動画をクライアント専用ページ（GitHub Pages または SCORM対応LMS）へ自動デプロイ。 月次更新を GitHub Actions のスケジュール実行で自動化。
4
AI-SDR：七那華がパーソナライズ提案動画を見込み客に自動送付
見込み法人の業種・課題に合わせた「御社向けDX研修デモ動画」を自動生成し、 メール or SNS で自動アウトリーチ。七那華が24時間営業担当として稼働。
