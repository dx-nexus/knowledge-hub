INFRASTRUCTURE SETUP GUIDE

Cloudflare Pages + Zero Trust
初期構築手順

📅 作成: 2026年5月 🎯 対象: knowledge-hub ポータル ⏱ 所要時間: 約60〜90分 💰 コスト: $0/月（50名まで無料）
目的： GitHub Pages（公開・認証なし）から Cloudflare Pages + Zero Trust（認証付き・承認メアドのみアクセス可）へ移行する。
完了後のURL： https://knowledge-hub-7ih.pages.dev（OTPメール認証で保護）
前提： GitHubアカウント（個人）・ポータルリポジトリ（dx-nexus/knowledge-hub）が存在すること。
1
Cloudflareアカウント作成
所要: 約5分
操作 1-1. アカウント登録
①
ブラウザで以下URLを開く
https://dash.cloudflare.com/sign-up
②
Googleアカウント連携でサインアップ（メール・パスワード入力不要）
③
「Welcome! How do you plan to use Cloudflare?」画面 → Personal を選択
④
「What best describes your role?」画面 → Information technology (IT) を選択
2
Cloudflare Pages デプロイ
所要: 約15分
操作 2-1. Pages作成画面へ遷移
①
ダッシュボード左メニュー → Workers & Pages をクリック
②
右上 Create application をクリック
③
画面下部「Looking to deploy Pages?」横の Get started をクリック
⚠ 「Create a Worker」ではなく必ず下部の「Get started（Pages用）」を選ぶこと。Worker経由でデプロイするとURLに個人アカウント名が含まれる。
操作 2-2. GitHubリポジトリ接続
①
Import an existing Git repository → Get started をクリック
②
Continue with GitHub をクリック（GitHub OAuth認証が走る）
③
左上アカウントドロップダウンで fooueen → dx-nexus に切り替え
④
検索欄に knowledge-hub と入力 → 表示されたリポジトリをクリック
⑤
右下 Next をクリック
操作 2-3. デプロイ設定・実行
①
「Set up builds and deployments」画面 → すべてデフォルトのまま
②
右下 Save and Deploy をクリック
③
「Building and deploying」画面で全ステップが ✓ になるまで待機
④
「Success! Your project is deployed」と表示されたら完了。表示されたURLを控える
例: https://knowledge-hub-7ih.pages.dev
3
Zero Trust 認証設定
所要: 約20分
操作 3-1. Zero Trust有効化
①
左メニュー下部 Zero Trust をクリック
②
右上 Get started をクリック
③
「Choose a plan」画面 → 左列 Zero Trust Free の Select plan をクリック
④
「Activate Zero Trust Free」画面でクレジットカード情報を入力（請求額: $0/月）
⑤
「Purchase complete」と表示されたら完了
ℹ カード登録は必須ですが、Zero Trust Freeは50名まで完全無料です。
操作 3-2. ポリシー作成
①
Zero Trustダッシュボード左メニュー → Access controls → Policies
②
左下 Add a policy をクリック
③
Policy name 欄に approved-users と入力
④
Action: Allow（デフォルト）
⑤
「Configure rules」→ Include セクション → Selector: Emails を選択
⑥
Value 欄にアクセスを許可するメールアドレスを1件ずつ入力
⑦
右下 Save policy をクリック
ℹ ドメイン縛り（@会社名.co.jp）ではなく個別メアド方式を推奨。社外関係者への個別付与・削除が柔軟に行える。
操作 3-3. Accessアプリ作成
①
左メニュー → Access controls → Applications
②
右上 + Create new application をクリック
③
「Add an application」モーダル → 内側タブ Public DNS をクリック
④
下部 Continue with Self-hosted and private をクリック
⑤
「Destinations」セクション → Switch to custom input をクリック
⑥
入力欄に knowledge-hub-7ih.pages.dev と入力（フェーズ2で控えたURL）
⑦
下にスクロール → 「Details」セクション
⑧
Details > Name: knowledge-hub と入力
⑨
Details > Session Duration: 24 hours（デフォルト）
⑩
右下 Create をクリック
操作 3-4. ポリシーをアプリに紐付け
①
Applications一覧 → knowledge-hub をクリック
②
上部タブ Policies をクリック
③
中央右 Add current policies ドロップダウンをクリック → approved-users を選択
④
右下 Save をクリック
4
旧環境の整理
所要: 約10分
操作 4-1. GitHub Pages無効化
①
以下URLを開く
https://github.com/dx-nexus/knowledge-hub/settings/pages
②
ページ上部の Unpublish site ボタンをクリック
③
「GitHub Pages unpublished.」と表示されたら完了
⚠ Source欄に「None」オプションは表示されない。必ず「Unpublish site」ボタンを使用すること。
操作 4-2. リポジトリPrivate化
①
GitHub リポジトリ Settings → 左メニュー General をクリック
②
ページ最下部「Danger Zone」まで スクロール
③
Change visibility → Make private をクリック
④
確認ダイアログに dx-nexus/knowledge-hub と入力
⑤
I understand, change repository visibility をクリック → GitHub認証
操作 4-3. 旧Worker削除
①
Cloudflareダッシュボード → Workers & Pages
②
リストの knowledge-hub.fooueen.workers.dev（Worker版）右端 … をクリック
③
View settings をクリック
④
設定画面最下部の Delete をクリック → 確認入力 → 削除実行
⚠ 「…」メニューに直接「Delete」は表示されない。必ず「View settings」経由で最下部のDeleteを使用すること。
5
動作確認
所要: 約5分
操作 5-1. OTP認証テスト
①
Chromeのシークレットウィンドウ（Ctrl+Shift+N）を開く
②
以下URLにアクセス
https://knowledge-hub-7ih.pages.dev
③
「Cloudflare Access」のメールアドレス入力画面が表示されることを確認
④
approved-usersに登録したメールアドレスを入力 → Send me a code
⑤
メール受信ボックスにOTPコード（6桁）が届いていることを確認
⑥
コードを入力 → Verify → ポータルが表示されることを確認
✅ 構築完了 — 正式URL
https://knowledge-hub-7ih.pages.dev
・認証なしではアクセス不可（Zero Trust保護）
・approved-usersポリシーに登録したメアドのみOTP認証でアクセス可能
・GitHubリポジトリはPrivate化済み（ソースコード非公開）
・GitHub Pages旧URLは無効化済み
・新規メンバー追加：Cloudflare Zero Trust → Access controls → Policies → approved-users → メアドを追加
