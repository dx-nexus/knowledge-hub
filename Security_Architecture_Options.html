Analogy — 01

一言でいうと、どんな鍵か。

🔐
OPTION A
Vercel Pro + Basic認証
「マンション全体に南京錠を1つかけた状態」
— ドアの前に来た人全員が同じ鍵を持っている。
合言葉を知っている人は誰でも入れる。家族全員に合言葉を渡す感覚。合言葉が漏れたら全員アウト。でも設置は5分でできる。
🏰
OPTION B
Cloudflare Pages + Zero Trust
「顔認証＋玄関カメラ＋入館証のある要塞」
— 登録したメールアドレスの持ち主だけが、ワンタイムPINで入れる。
NTTデータ社員など特定ドメインのメール保有者だけを許可できる。1人ずつの入退記録が残る。設定に3〜5時間かかるが、50名まで無料。

Recommendation — 04

Gemini + Claudeの推奨。

長期的に見れば、Cloudflare Zero Trustが圧倒的に有利。
だが今すぐ動きたいならVercelから始めて移行も選択肢。

コスト面ではCloudflareが50名まで無料と明確に優位。Vercelは$20/月かかるうえ、Basic認証は共有パスワードという根本的な弱さを持つ。
一方でCloudflareの設定は初見では複雑で、特にZero TrustのPolicy設定はCloudflareの独自UIに慣れが必要。
Geminiの強い推奨はCloudflare。Claudeも同意見。

VERCEL を選ぶなら
・今週中に動かしたいときの暫定措置
・アクセスするのが完全に信頼できる社内メンバーのみ
・将来的にCloudflareへの移行前提でOK
・とにかく設定を簡単に済ませたい
CLOUDFLARE を選ぶなら
・本番運用の最終形として最初から正しく作りたい
・NTTデータ等のクライアントに共有する可能性がある
・コンプライアンス上、入退記録が必要
・無料で企業レベルのセキュリティを実現したい

03
