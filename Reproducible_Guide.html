本PoCは、作業領域を完全に独立した箱として用意することで、親リポジトリとのGitネストを100%回避します。実働コンポーネントは C:\git\pmo-automation\ に配置し、ここでのみコード生成・実行・テストを行います。

表示系（`hancho-docs`）は参照用ポータルにとどめ、実行系（`pmo-automation`）と疎結合に維持します。変更は実働箱側で完結し、ポータルはリンクカードで誘導します。

トラブルシューティングと掃除

404エラーA: Pages表口とPushの違い

Pagesの公開URL（例: https://dx-nexus.github.io/knowledge-hub/）は静的ホスティングURLであり、Gitのpush先ではありません。pushは裏口（例: https://github.com/dx-nexus/pmo-automation.git）を指定してください。

404エラーB: Privateリポジトリの可視性

リポジトリをPrivateにしていると、権限がないと404が返る仕様です。公開化する場合は Settings → Danger Zone → Change repository visibility を操作してください（社内規程に従う）。

ワーキングツリー掃除

一時ファイルの削除例:

del /f /q commit_msg.txt
git status --short
リモート連携とハブ統合

リモート登録コマンド

git remote remove origin
git remote add origin https://github.com/dx-nexus/pmo-automation.git
git push -u origin main

README化によるトップページ表示

`PROJECT_TOTAL_SUMMARY.md` を `README.md` にリネームすると、GitHubのリポジトリトップに内容が自動でレンダリングされます。手順は以下の通りです。

git mv PROJECT_TOTAL_SUMMARY.md README.md
git commit -m "docs: rename summary to README for GitHub rendering"
git push
