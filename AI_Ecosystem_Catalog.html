VS Code / ローカル端末を「ニュートラルな実行ステージ」と定義し、戦略・実装・表現のAIを可視化。サルでも直感理解できるように、左右／上下の対比で役割を整理しました。

4つの役割カテゴリ
🧭
カテゴリ1
ニュートラル実行空間 / コックピット

VS Code とローカルターミナルが、AIたちの手足を与える「唯一無二のステージ」。知能は持たないが、すべてのAIを公平に動かす基盤であり、生成と実行の出発点。

VS Code

タグ管理・ファイル編集・ターミナル操作を中立に提供。あらゆるAIがアクセスしうる「実行環境の司令台」。

ローカルターミナル

git・ビルド・デプロイ・スクリプト実行を担当。AIの命令を外部システムに橋渡しする肉体的な作業領域。

🧠
カテゴリ2
戦略・思考型LLM / 総括司令官

Claude と Gemini が「戦略立案と要件設計」を担う最高頭脳。曖昧な人間の意図を解像度高く翻訳し、プロジェクト全体の方向性を描きます。

Gemini

200万トークンの俯瞰力で全体を把握し、長大ドキュメントを横断的に整理。戦略設計・依存関係・進化ロードマップの統括。

Claude

高精度な文章構成力でプロンプト・要件定義・設計書を生成。意図を正確に構造化し、実装エージェントへの橋渡しを行う。

⚙️
カテゴリ3
実装・執行エージェント / 爆速パイロット

Claude Code と GitHub Copilot (Codex) が、設計図を受けて実際にコードとファイルを変更する現場の職人。Terminal Auto-Approval と組み合わせることで、自律実行が成立します。

Claude Code

構造化された要件をもとにHTML・スクリプト・CI設定を生成し、git操作まで自動化する実装エンジン。

GitHub Copilot (Codex)

エディタ内での補完・リファクタリング・修正提案を提供。実装速度を加速しつつ、開発フローに自然に溶け込む。

✨
カテゴリ4
マルチモーダル・インターフェース / 表現エンジン

Google Spark が音声・映像・リアルタイムインタラクションを司るフロント表現。成果物を人間に見せるためのプレゼンターとして、直感的なデモと翻訳を担当します。

音声・映像表現

完成物を対話的に説明し、実演やデモを自然な形で提示。ユーザーの理解を助けるプレゼンテーション層。

リアルタイム変換

生成結果を即座に翻訳・再構成し、AIの出力を人間にとって意味ある形に再提示する。
