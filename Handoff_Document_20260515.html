④ 運用ルール（次セッション以降への申し送り）

📌 今日の事故から学んだ恒久ルール：

ルール背景
CSS CSS修正は追加のみ・削除禁止（!important使用）CSS大量削除でJSが破損→「showTab is not defined」エラー発生
PS PowerShellの > / Out-File はファイル破壊リスクエンコーディング変換で日本語が文字化け／Copy-Item か Invoke-WebRequest を使う
DL Downloadsの古いファイル混在事故Sort-Object LastWriteTime -Descending で最新自動特定（deploy.ps1に実装済み）
確認 ブラウザキャッシュ問題動作確認はシークレットウィンドウで（または Ctrl+Shift+R）
Code Claude Code の権限確認スキップ--permission-mode acceptEdits または Shift+Tab で auto-accept
復元 壊れた時は Git の朝コミットに戻すgit checkout {hash} -- {file} で安全復元
運用フロー（毎回これだけ）
# 1. Claudeからファイルをダウンロード # 2. deploy.ps1 を1コマンド実行（コピー → vault push → docs同期push） cd C:\git\hancho-kb .\scripts\deploy.ps1 "コミットメッセージ" # 3. 公開URLを確認（シークレットウィンドウ推奨）
