## 確定事項（要項の原文に基づく）

| 項目 | 内容 |
|---|---|
| 募集内容 | 京都を題材とする**未発表**の「小説」（ジャンル不問） |
| 締切 | **2027年5月10日（月）20時**（郵送は同日消印有効） |
| 字数（一般部門） | **28,000字以上 160,000字以内** |
| 応募点数 | **一人一編** |
| 応募資格 | 年齢・国籍を問わない |
| 提出形式 | 応募フォーム又は郵送。**Word又はPDF**。一般部門は手書き不可 |
| 著作権 | 応募者に帰属。あらすじ・一部が主催者媒体に掲載されることがある |

## 「未発表」の定義（最重要）

> 「未発表のものに限ります」
> 「インターネット上で掲載された作品や、同人雑誌、自費出版物等で発表された作品については、
> **営利を目的としていないものに限り、未発表とみなし応募を受け付けます**」

→ **非営利のWeb公開は「未発表」扱いとなる。** GitHub Pages等での無償公開は応募の妨げにならない。

> 「他の文学賞との**二重投稿**及び過去に入選した作品の応募は禁止します」

→ 他賞との同時応募は不可。公開そのものより、こちらの制約のほうが厳しい。

## 未確認・要検討

- **「京都を題材とする」の判断基準は要項に明記がない。** 事務局（075-241-6172）に確認する余地あり。
- 現原稿26節に、京都と特定できる固有名詞・地理の記述がほぼない。
  スタイル語彙として「電子枯れ竹林」「シリコン枯山水」があり、
  廃墟フレームが京都の想定である読み筋は立つが、**題材性の主張としては弱い。**
- 当初想定していた締切「2026年10月31日」は公式情報と一致しない。別の賞を指していた可能性がある。

## 本作への影響

1. **締切に8か月弱の余裕ができた**（2026-09-17時点で約8か月）。
2. **Web公開は可能**。ただし非営利であることと、他賞への二重投稿をしないことが条件。
3. **京都の題材性の補強が必要。** 第3章「領域」で地理・固有名詞を入れるのが最も自然な位置。
   フレームの廃墟が京都であることを、読者が確定できる情報を配置する。
4. 応募は一人一編。『ペリエの栞』と同じ回に併願はできない。
