# 『京都事変2026』章別プロット v002

**このファイルの用途**：執筆パイプラインv2が「いま、どこを書くべきか」を判定するための行き先定義。

## v001からの変更理由

v001は1節5,000字を想定していたが、実測（基準原稿3節）は**平均2,418字で到達点に達した**。5,000字は過大であり、この乖離が `currentSection_` の節番号を逆行させていた。

そこで**節あたり2,500字を正とし、節数を増やす**。総字数は維持する。

| | v001 | v002 |
|---|---|---|
| 節あたり | 5,000字 | **2,500字** |
| 第1〜3章 | 各6節 | **各12節** |
| 第4章 | 5節 | **10節** |
| 総節数 | 21節 | **46節** |
| 目標総字数 | 115,000字 | **115,000字** |

原稿用紙換算 約288枚。募集要項の250〜400枚に収まる。

## 7. パイプラインv2への接続（v002で修正）

### 7-1. `extractChapterPlot_`（正規表現をやめて行走査へ）

v001に記載した正規表現版は、`m` フラグ下で `$` が行末にマッチするため**見出し1行（25字）しか返さない**。実測で確認済み。次に差し替えること。

```javascript
function extractChapterPlot_(fullPlot, chapterNo) {
  const lines = fullPlot.split("\n");
  const head = new RegExp("^## \\d+\\. 第" + chapterNo + "章");
  const start = lines.findIndex(function(l) { return head.test(l); });
  if (start < 0) return fullPlot;
  let end = lines.length;
  for (let i = start + 1; i < lines.length; i++) {
    if (/^## \d+\. /.test(lines[i])) { end = i; break; }
  }
  return lines.slice(start, end).join("\n");
}
```

### 7-2. `currentSection_`（字数割り算をやめてカウンタ管理へ）

**字数からの逆算は使わない。** 節ごとの実測字数がばらつくため、割り算では必ずずれる。完了節数をスクリプトプロパティで持つ。

```javascript
function sectionCountOf_(chapterNo) { return (chapterNo === 4) ? 10 : 12; }

/** いま書くべき節番号 */
function currentSection_(chapterNo) {
  const done = Number(PropertiesService.getScriptProperties()
                        .getProperty("DONE_SEC_CH" + chapterNo) || 0);
  return chapterNo + "-" + Math.min(done + 1, sectionCountOf_(chapterNo));
}

/** 追記成功後に1つ進める */
function markSectionDone_(chapterNo) {
  const props = PropertiesService.getScriptProperties();
  const key = "DONE_SEC_CH" + chapterNo;
  const done = Number(props.getProperty(key) || 0);
  props.setProperty(key, String(Math.min(done + 1, sectionCountOf_(chapterNo))));
}

/** 手動シード：基準原稿を投入したら実行して完了節数を合わせる */
function seedDoneSections() {
  const props = PropertiesService.getScriptProperties();
  props.setProperty("DONE_SEC_CH1", "3");   // 1-1〜1-3 は執筆済
  props.setProperty("DONE_SEC_CH2", "0");
  props.setProperty("DONE_SEC_CH3", "0");
  props.setProperty("DONE_SEC_CH4", "0");
  console.log("完了節数をシードしました。第1章は 1-4 から開始します。");
}
```

**`buildPrompt_` の変更**

```javascript
const plotAll = readDocText_(novelFolder, "03_章別プロット", true);
const plot    = extractChapterPlot_(plotAll, chapterNo);
const sec     = currentSection_(chapterNo);          // ← 字数を渡さない
```

**`writeNextChunk` の変更**：`appendToLog_(novel, no, "OK", generated);` の直後に1行追加する。

```javascript
markSectionDone_(no);
```

### 7-3. 目標字数の変更

`updateProgress_` の `TARGET_PER_CHAPTER = 30000` を、章別に変更する。

```javascript
function targetOf_(chapterNo) { return sectionCountOf_(chapterNo) * 2500; }
// 第1〜3章: 30,000 / 第4章: 25,000
```

### 7-4. `maxOutputTokens`

`8192` では日本語2,900字前後で `finishReason = MAX_TOKENS` に当たる（実測）。**`16384` へ引き上げること。**

### 7-5. 適用順序

1. `extractChapterPlot_` 差し替え
2. `currentSection_` / `markSectionDone_` / `seedDoneSections` 追加
3. `maxOutputTokens` を16384へ
4. `10_本文/第1章` を**全消去**し、基準原稿3節（7,254字）を投入
5. `seedDoneSections()` を1回実行
6. `writeNextChunk(1)` → **1-4が出力されるか**を確認
